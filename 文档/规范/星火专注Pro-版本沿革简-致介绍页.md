## 一、一句话定位（可直接用于卡片 / 书信）

**第二部 · 星火专注Pro —— 守护专注。**
点火即专注，满一个时段就铸一颗星；链断了不必羞愧，历史最长的那条链永远替你留着。

三个词就够：**星链**＝专注次数，**判例**＝合理中断的永久规则，**国策**＝长期习惯。

---

## 二、三部曲主线的第二部那一环（供 epilogue 书信措辞）

- 第一部 守护**牵挂**
- 第二部 守护**专注** ← 本部
- 第三部 守护**表达**

第二部的独特处，在于它**不惩罚中断**：
不是「断了就清零」的打卡，而是把「中断」交给用户自己裁判——立为判例，则同类情况从此放行，且本次照样铸星。

> 若书信里要写一句第二部的骨，可用：
> **「它记的不是你的自律，是你愿意坐下来的次数。」**

## 三、当前版本能做什么（功能细目，供特色卡片）

| 模块 | 实情 |
|---|---|
| 点火 → 计时 → 铸星 | 25 分钟专注；点火仪式（火种→火舌→星链逐颗点亮→烟花→收束），音效 WebAudio 现场合成 |
| 星链 | 断链只记最长，历史最长永不磨损；星链长卷可逐颗回看（任务/时长/推进）；第 7/30/100 颗触发流星雨 |
| 判例系统 | 中途打断由用户裁判：**断链** 或 **立为判例**（此后同类原因自动放行，本次照铸星） |
| 预约入座 | 定时预约 + 迟到/缺席处理 |
| 热身模式 | 5 分钟微型专注 + 收束决策 |
| 复盘 | 每日三栏（好事 / Idea / Thinking）+ 了解赢级（小赢/中赢/大赢） |
| **星火来信**（v1.2.0 新） | 复盘写完自动封存为一封信；全屏信纸阅读、当日星语附于信尾；信笺匣按日期排列，点哪封读哪封；读信时背景乐《月亮代表我的心》安静相伴 |
| 国策星树 | 每天最多点亮一条低阻力规则；每守住一天内化生长——连续 7 天进 **E1·生根**、21 天成 **E2·成树**；熄灭入回收箱可恢复或永久删除 |
| 静场（六种声音） | 白噪 / 粉噪 / 棕噪 / 雨声 / 海浪 / 篝火；雨声篝火为真实录音，海浪与三噪为浏览器现场合成；**全部不联网** |
| 背景乐 | 《月亮代表我的心》钢琴版，整站背景乐、默认开启；点火入专注自动停，暂停或结束接着放 |
| 星月诗笺 | 30 句星月诗词，分 5 组（星河 / 月夜 / 疏星淡月 / 夜风与晓 / 人间星语）；点火页每日一句「今日星语」，专注中安静显示 |
| 年度星图 | Canvas 本地直绘 1080×1440，含星数/最长链/月度分布/最常投入，导出 2 倍 PNG，**不上传** |
| 备份中心 | 导出 JSON、导入预检（先报将合并多少条）、本机自动快照（最新+最近 6 次，主数据写坏可自愈） |
| 其他 | PWA 可安装、离线可用、首启三屏引导、极简/高级双模 |

## 五、修书时务必核对的三个数字／表述

1. **版本号**：写 **v1.2.0**。此前书信若写 v1.0 或 v1.1，皆为旧话。
2. **背景乐的定位已变**：v1.1.0 时它只是「专注背景乐」，**v1.1.1 起改为整站背景乐、打开网页即播**。若书信仍写「点火时才响起」，与实不符。
3. **静场是六种，不是三种**：白/粉/棕是合成，雨/浪/火是自然声（雨与火为真实录音）。v0.6.0 时确为三种，现已扩至六种。
