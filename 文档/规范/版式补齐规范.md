## 零、先立设计令牌（后面所有版式都从这三个刻度长出来）

所有间距吸附 **8 的倍数**，所有字号从 **固定字阶** 取值。禁止在版式里写裸数值。

```css
:root{
  /* ── 8px 网格 ── */
  --u: 8px;
  --s1: calc(var(--u) * 1);   /*  8px  元素内间距 */
  --s2: calc(var(--u) * 2);   /* 16px  元素间 */
  --s3: calc(var(--u) * 3);   /* 24px  组间 */
  --s4: calc(var(--u) * 4);   /* 32px  区块间 */
  --s5: calc(var(--u) * 6);   /* 48px  大区块 */
  --s6: calc(var(--u) * 9);   /* 72px  页级留白 */

  /* ── 页级 gutter（同层级元素左边缘必须共线，靠它保证）── */
  --gutter-x: calc(var(--u) * 10);   /* 80px 左右安全边距 */
  --gutter-y: calc(var(--u) * 8);    /* 64px 上下安全边距 */

  /* ── 字阶 2.4 : 1 : 0.72 ── */
  --fs-body:  20px;
  --fs-title: calc(var(--fs-body) * 2.4);   /* 48px */
  --fs-sub:   calc(var(--fs-body) * 1.3);   /* 26px 副标题/导语 */
  --fs-note:  calc(var(--fs-body) * 0.72);  /* 14.4px 注释/收束句 */
  --fs-hero:  calc(var(--fs-body) * 3.2);   /* 64px KPI 大数字 */

  /* ── 行高 / 字重 ── */
  --lh-title: 1.18;
  --lh-body:  1.62;
  --fw-title: 700;
  --fw-body:  400;

  /* ── 中性色（配色按主题覆盖，这里只给对比度达标的默认）── */
  --c-ink:    #101828;
  --c-sub:    #475467;
  --c-note:   #667085;
  --c-rule:   #D0D5DD;   /* 细线，替代圆角卡片边框 */
  --c-accent: #B54708;
  --c-bg:     #FFFFFF;
}
```

**行长约束**（中文正文一行 20–28 字）：`20px × 28 = 560px`，所以正文容器最大宽度锁 `--measure`。

```css
:root{ --measure: 28em; }   /* 约 560px，超出必须分栏或缩字号，不许拉满整行 */
```

## 一、每页统一骨架（三种版式共用的地基）

```css
.page{
  position: relative;
  box-sizing: border-box;
  padding: var(--gutter-y) var(--gutter-x);
  background: var(--c-bg);
  color: var(--c-ink);
  display: flex;
  flex-direction: column;
  line-break: strict;              /* 避头尾：标点不出现在行首 */
  text-spacing-trim: space-first;  /* 中英混排标点收紧（支持则生效）*/
}
.page > *{ min-height: 0; }        /* 允许子项收缩，防止 flex 溢出 */

/* 标题即结论：标题区不换行超过 2 行 */
.page .h{
  font-size: var(--fs-title);
  line-height: var(--lh-title);
  font-weight: var(--fw-title);
  max-width: 22ch;
  margin: 0 0 var(--s4);
  letter-spacing: .01em;
}
.page .h .sub{
  display: block;
  font-size: var(--fs-sub);
  font-weight: var(--fw-body);
  color: var(--c-sub);
  margin-top: var(--s2);
  max-width: var(--measure);
}

/* 内容区吃掉剩余高度 */
.page .body{ flex: 1 1 auto; min-height: 0; }

/* ── 底部收束条（对应 note 字段，此前被整个丢掉）── */
.page .note{
  flex: 0 0 auto;
  margin-top: var(--s4);
  padding-top: var(--s2);
  border-top: 1px solid var(--c-rule);   /* 细线，不用圆角盒 */
  font-size: var(--fs-note);
  line-height: 1.5;
  color: var(--c-note);
  max-width: var(--measure);
}
.page .note::before{
  content: "所以呢 — ";
  color: var(--c-accent);
  font-weight: 600;
}
```

> **渲染契约**：`s.note` 有值就渲染 `.note`，没值就**不渲染空条**（避免出现一条孤零零的细线）。

## 三、渲染契约自检（防止再次静默降级）

`LAYOUT_DOC` 声明的每个 layout，**必须**在渲染器里有显式分支。落不到分支就报错，不许走 `else` 兜底成列表。

```js
const DECLARED = ["cover","closing","bullets","two_col","grid","kpi","timeline",
                  "steps","compare","quote","table","zigzag"];

const RENDERED = {                       // 渲染器真实能力集
  cover:coverHTML, closing:closingHTML, bullets:bulletsHTML, two_col:twoColHTML,
  grid:gridHTML, kpi:kpiHTML, timeline:timelineHTML, steps:stepsHTML,
  compare:compareHTML, quote:quoteHTML, table:tableHTML, zigzag:zigzagHTML
};

function assertLayoutContract(){
  const missing  = DECLARED.filter(k => typeof RENDERED[k] !== "function");
  const undeclared = Object.keys(RENDERED).filter(k => !DECLARED.includes(k));
  if (missing.length)    console.error("[layout] 声明了但画不出：", missing);
  if (undeclared.length) console.warn ("[layout] 画得出但未声明（AI 不会用）：", undeclared);
  return missing.length === 0;
}

function pageHTML(s){
  const fn = RENDERED[s.layout];
  if (!fn){
    console.error("[layout] 未知版式，已阻止静默降级：", s.layout);
    return renderFallback(s);            // 兜底也要在 UI 上可见地标注
  }
  return fn(s);
}
```

**同时删掉 `cards`**（`LAYOUT_DOC` 里没有它），或把它补进 `LAYOUT_DOC` —— 二选一，不能继续错位。

## 四、PPTX 导出必须同步

网页端补齐 11 种版式后，`buildPptxScript()` 的三分支（cover / closing / else）依然是「全要点列表」。两条渲染路径共用同一份 `layout` 决策，导出侧至少实现：**kpi / timeline / compare / quote / list** 五种，否则「导出后失真」会成为新的投诉点。

建议：把版式语义抽成一份 `LAYOUT_SPEC` 数据，网页渲染器和 PPTX 生成器都从它推导，避免两边各写一套。

## 五、交付前的三条断言（自动化，别靠肉眼）

```js
// ① 版式覆盖：生成 8 页 deck，实际出现 ≥ 4 种不同 layout
const kinds = new Set(pages.map(p => p.layout));
console.assert(kinds.size >= 4, "版式过于单调");

// ② 静默降级：没有任何一页落到 fallback
console.assert(!pages.some(p => !RENDERED[p.layout]), "存在未实现版式");

// ③ 字号层级：标题/正文/注释 ≈ 2.3~2.5 : 1 : 0.65~0.8
const r1 = parseFloat(getComputedStyle(title).fontSize) / parseFloat(getComputedStyle(body).fontSize);
const r2 = parseFloat(getComputedStyle(note ).fontSize) / parseFloat(getComputedStyle(body).fontSize);
console.assert(r1 >= 2.3 && r1 <= 2.5, "标题字阶越界");
console.assert(r2 >= 0.65 && r2 <= 0.8, "注释字阶越界");
```

外加**几何自检**（下一轮做）：离屏渲染后量 `getBoundingClientRect()`，检测
- 元素重叠（两个兄弟节点矩形相交面积 > 0）
- 文字溢出（`scrollHeight > clientHeight + 1`）
- 出界（rect 超出 `.page` 的 padding 盒）
- 溢出兜底：命中就把该页字号降一档重排，最多降两次

## 六、落地顺序（按收益，不按难度）

| 顺序 | 事项 | 为什么先做 |
|---|---|---|
| 1 | 渲染 `.note` 收束条 | 设计里已经要求了，前端白扔了，改动最小 |
| 2 | `kpi` 大数字版式 | 视觉冲击最强，一张图就能看出「不一样了」 |
| 3 | `timeline` 竖线轴 | 结构感，且天然非均分 |
| 4 | 版式契约自检 | 防止后面再出现「说了画不出」 |
| 5 | `zigzag` + `compare` + `quote` | 消灭均分、增加呼吸节奏 |
| 6 | `steps` / `table` / `grid` | 补齐完整度 |
| 7 | PPTX 导出同步 | 网页好看了，导出不能拖后腿 |
