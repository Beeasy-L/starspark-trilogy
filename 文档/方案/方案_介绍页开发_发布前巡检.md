### AC-4 补：若加「文件指纹」检查，必须比内容不比字节

评审补充提醒（群管理 13:18 实测）：本仓 `core.autocrlf = true`，**工作区是 CRLF、仓里是 LF**。

我实测四页字节差：

```
index.html  仓 14,753 / 磁盘 14,956  (+203)      focus.html  仓 15,783 / 磁盘 16,056  (+273)
streak.html 仓  9,222 / 磁盘  9,389  (+167)      ppt.html    仓 18,087 / 磁盘 18,380  (+293)
```

**所以任何「工作区哈希 == 仓哈希 == 线上哈希」的断言都有歧义。** 我 13:17 就踩过一次：发给三审的四页 SHA256 是**磁盘版**，与仓库/线上对不上。

**正确写法**：
```python
# 比内容，不比字节：先归一化行尾再算
sha256(content.replace(b'
', b'
'))
```

**取仓库版的正确命令**（第三人可复现）：
```powershell
git show HEAD:projects/ppt.html | sha256sum      # 仓版，与线上一致
sha256sum projects/ppt.html                      # ❌ 磁盘版，含 CRLF，对不上
```

> 这条不影响本方案的 AC-2 ② 与 AC-4（都不涉及哈希），但**如果后面加指纹检查，必须按上面写**。
