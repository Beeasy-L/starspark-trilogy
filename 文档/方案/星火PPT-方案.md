## 一、产品一句话

一个**全栈网页**：用户粘贴一段文案（可选上传参考资料 / 图片），选一个「应用方向」和「一套模板」，点生成，**AI 大模型**把内容拆解成多页 PPT，前端实时流式展示 **逐页生成过程**，支持切换主题、编辑每页、放映演示，最后**导出为独立 HTML 文件**，并在本地自动留存历史可回看续编。

## 二、形态与技术栈（已按你确认的「1」定死）

| 层 | 形态 | 说明 |
|---|---|---|
| **后端** | Python 标准库小服务（`http.server` + `http.client`） | 沿用系列铁律 **零新增依赖**；负责调 DeepSeek、转发流式、静态托管 |
| **前端** | **单文件 `星火PPT.html`**（CSS/JS 内嵌、无构建） | 双击即用、离线可渲染、延续前两部 UI |

| **历史** | localStorage 存草稿 + 可导出 JSON 备份 | 自动保存、可回看继续编辑 |

## 三、核心功能

### 1. 输入区
- 大文本框：粘贴长文案（核心）
- 「可选」上传参考资料：PDF / txt / md / 图片（后端读取文本一起送给模型）
- 应用方向选择（预设 4-6 个）
- 模板选择（多套配色 + 版式）
- 「生成」按钮

### 2. 应用方向预设（AI 按方向调整语气与结构）
- **职场报告**（工作汇报 / 述职）
- **商业计划**（BP / 融资路演）
- **教育课件**（讲义 / 课程）
- **活动方案**（策划 / 执行）
- **学习笔记**（知识梳理）
- **通用文案**

> 每个方向内置一套「结构 + 语气 + 文案风格」提示模板（这就是你要求的 **PPT skill** 一部分）。

### 3. 模板体系（多套供选择）
- 内置 **4~6 套模板**，每套 = 配色主题 + 版式风格 + 适用方向推荐
- 延续星火系列视觉语言（星空夜蓝 + 金色火焰 + 衬线）为主，另配几套商务/教育风格
- 用户可存自己常用的模板偏好

### 4. 流式生成
- 点生成后，后端流式返回，前端**逐页实时展示**：先出大纲 → 再逐页填文案 → 当前正在生成哪页高亮动效
- 可中断生成

### 5. 结果区
- 左侧页缩略图，右侧当前页编辑
- **可编辑**：改每页标题 / 正文 / 重生成某一页
- 主题 / 模板可切换应用到整个 deck
- 键盘翻页 + 全屏**放映模式**（演示给观众看）

### 6. 导出 & 历史
- **导出独立 HTML**：一份自包含文件，双击即全屏可演示
- 导出 JSON 备份
- **本地历史**：每次生成自动存 localStorage 列表，够恢复继续编辑
- 删除 / 清空历史
