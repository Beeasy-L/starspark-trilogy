## 四、⚠️ 一条要改（不阻塞，但冻结前必须补）

### 问题：手工内联会让 `dev/anim.js` 与 `static/index.html` 漂移

方案第 2 节写：
> `产品\星火PPT\static\index.html`：① 内联 anim.js 全文（IIFE）

**这已经是第三次手工内联**：`bgm.js` 已内联、`anim.js` 将内联、`decorations/poems/templates/blueprints` 都已内联。

`static\index.html` 现在 **384.7 KB / 约 7,000 行**。手工内联的问题是：

```
dev/anim.js         ← 真源（我交付的 12.9 KB）
static/index.html   ← 手工粘贴的副本
```

**改 `dev/anim.js` 不会影响已内联的副本**，反之亦然。两次之后没人知道哪份是准的。

### 建议加一条验收（**V5**）

> **内联后必须验证 `dev/anim.js` 与 `static/index.html` 内联段逐字一致。**

可复现做法（第三方照做）：
```powershell
$R = "C:\Users\saucc\Desktop\星火三部曲"
# 取 dev 源文件的规范化哈希
$devHash = (Get-FileHash "$R\产品\星火PPT\dev\anim.js" -Algorithm SHA256).Hash
# 从 static 里把内联段抠出来（按起止标记），比对
# 若做不到抠取，至少断言：static 里含 dev 的全部函数名，且行数与 dev 相近
Select-String -Path "$R\产品\星火PPT\static\index.html" -Pattern 'function createAnim|function orchestrate|function onStageChange'
#   期望：三处全部命中
```
**期望**：三处函数定义全部在 `static` 里能找到；且**行数差 ≤5%**（允许包一层 `<script>`）。

> 更彻底的解法是「构建期合并」（`dev/*.js` 为真源，脚本生成 `static/index.html`），
> 但那是**主公待决的四件事之一**，不在本轮范围。本轮只需**加一条一致性断言**，
> 让「内联漂移」从「没人发现」变成「检查会报」。

### 为什么这条值得加

我是 `anim.js` 的作者。**如果内联后有人只改 `dev/anim.js`，改动不会生效，而所有测试都会通过**——
因为测的是 `static/index.html`，它没变。**这是「验描述不验对象」的又一个变体：测了产物，没测产物与源的对应关系。**
